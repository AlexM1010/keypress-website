HELP

Error help.

When Keypress refuses to run a macro it says why, in a sentence. These are those sentences, with the usual causes and what to do. Words in <angle brackets> stand for the part that is specific to your macro.

Still stuck? Choose Report… on the message in the app. You see everything in the report before you send it, and nothing is sent until you press Send; the application privacy policy says what a report can hold. Anything still open is on the known issues page.

Keypress is closing

Error code app-shutting-down

What Keypress says

the app is shutting down

Why it happens

  • A hotkey or a tray click arrived while Keypress was quitting.

What to do

  1. Start Keypress again and run the macro. Nothing was started.

Claude is driving the machine

Error code authoring-in-progress

What Keypress says

an authoring session is going and Claude is driving the machine: stop it before running a macro, or the two would fight over the mouse and keyboard

Why it happens

  • A session in which Claude drives your mouse and keyboard is still going.
  • A macro was started from its hotkey or the tray during that session.

What to do

  1. Stop the session with the Stop button in the Assistant panel, then run the macro.

A test run is already open

Error code debug-session-active

What Keypress says

a debugger session is already attached to run <run>: stop it before starting another

Why it happens

  • Only one test run with a debugger can be open at a time, and one is still attached to an earlier run.

What to do

  1. Stop the test run in the Test run tab, then start the new one.

The macro has no steps

Error code empty-flowchart

What Keypress says

The macro has no steps in it. / the macro has no steps

Why it happens

  • The canvas is empty, or the macro file you opened has no steps in it.

What to do

  1. Add a Start and the steps after it, or open the macro you meant to run.

A setting has a value it cannot have

Error code field-value

What Keypress says

<step>: <setting> is <value>, and it has to be one of <words>. / <setting> is <n>, and it cannot be less than <m>.

Why it happens

  • A number is outside the range the setting allows, or a word is not one of its choices.
  • The macro file was edited by hand.

What to do

  1. Open the step and choose the setting again from its list.

The macro was saved by a newer version

Error code future-version

What Keypress says

<macro> is saved in file format version <n>, and this build of Keypress reads up to version <m>

Why it happens

  • The macro was made or saved in a newer version of Keypress than the one you are running.

What to do

  1. Update Keypress and open the macro again.
  2. Opening it in this version would run something other than what was saved, so Keypress will not.

A step is set to do something else, and nothing has been added

Error code if-fails

What Keypress says

<step>: If it fails is set to do something else, but nothing has been added to do yet.

Why it happens

  • A step is set to "Do something else" when it fails, but its If it fails lane is still empty.

What to do

  1. Add the steps to run instead to the step's If it fails lane, or set the step to stop the macro or carry on without it. Until then it carries on, as if it were set to carry on without it.

The macro could not be read

Error code invalid-macro-data

What Keypress says

invalid macro data: <detail>

Why it happens

  • The macro file was edited by hand and is no longer valid JSON.
  • A bug: the editor handed the app something it should not have.

What to do

  1. If you edited the file by hand, undo the edit or restore it from a copy.
  2. Otherwise this is a Keypress bug. Choose Report… on the message and send the report.

An If joins values that do not match

Error code join

What Keypress says

<step> joins <name> from <value> in Then and <value> in Else: the two have to be the same kind of value.

Why it happens

  • The two lanes of an If make values of different kinds, or only one lane makes it.
  • A step that made a joined value was deleted or changed.

What to do

  1. Open the If and remove the join, or change the steps in the lanes so both make the same kind of value.

A picture a step looks for is not on this computer

Error code missing-picture

What Keypress says

<step> has a way of finding its target by a picture, which is not on this machine.

Why it happens

  • The macro was copied to another computer without its pictures.
  • The picture file was moved or deleted.

What to do

  1. Pick the target again so the picture is taken afresh, or let the other ways of finding it do the work.

A step types a secret that is not saved

Error code missing-secret

What Keypress says

<step> is set to type a secret but none is chosen / the secret <name> is not saved on this computer.

Why it happens

  • The macro was made on another computer, and secrets stay on the computer that saved them.
  • The secret was deleted from Settings.

What to do

  1. Open Settings, add the secret again under the same name, and run the macro.

There is no Start to begin at

Error code no-start-node

What Keypress says

The macro has no Start, so there is nothing to begin at. / the macro has no Start step / no Start step <id> in this macro

Why it happens

  • The macro has no Start step, or it was deleted.
  • A hotkey or a button names a Start that has since been removed from the macro.

What to do

  1. Add a Start step and put the first step after it.
  2. If a hotkey was set on a Start you deleted, set it again on the one that remains.

Open app starts something unusual

Error code open-app-path

What Keypress says

<step> opens a script or shortcut rather than a program / a program outside the usual install locations.

Why it happens

  • The step opens a file Windows would run with whatever it associates with that type.
  • The program is outside the folders programs are normally installed in, which is worth a look if the macro came from someone else.

What to do

  1. Only keep the step if you know what the file does and trust where the macro came from.

A recording is in progress

Error code recording-in-progress

What Keypress says

a recording is in progress: stop it before running a macro, or the macro would drive the mouse and keyboard into the recording

Why it happens

  • You started a recording and have not stopped it.
  • A macro was started from its hotkey or the tray while you were recording.

What to do

  1. Stop the recording, with the Stop recording button or its stop key, then run the macro.

A step uses a value that is not there

Error code reference

What Keypress says

<step> uses <value>, which is made later / by a step that is not there / inside a lane that may not run.

Why it happens

  • The value is made by a step further down, so it does not exist yet when this step runs.
  • The step that makes the value was deleted, or the value is made inside an If or a Repeat and read after it.
  • The value is a different kind than the setting takes, such as text where a number is needed.

What to do

  1. Pick the value again from the list in the step: it offers only the values that are certain to exist at that point.
  2. Move the step that makes the value above the one that uses it, or read it inside the same lane.

A Repeat's condition cannot change

Error code repeat-condition-static

What Keypress says

<step> reads only values made before it, which nothing inside the loop can change.

Why it happens

  • The Repeat's while or until condition compares values made before the Repeat started, so every pass sees the same answer.

What to do

  1. Compare a value that a step inside the Repeat makes, or look at the screen instead.

A Repeat that never ends

Error code repeat-forever

What Keypress says

<step> repeats for ever and has no Stop repeating inside it, so only Stop can end it.

Why it happens

  • The Repeat is set to repeat for ever and nothing inside it leaves the loop.

What to do

  1. Add a Stop repeating inside an If in the Repeat, or choose how many times, or until what, to repeat.

A Repeat walks the wrong kind of list

Error code repeat-items

What Keypress says

<step> walks <value>, a list of <kind>, so its items are <kind>, but it is set to walk <other kind>.

Why it happens

  • The Repeat was set to walk text and the list it reads holds areas, or the other way round.
  • The step that makes the list was changed after the Repeat was set up.

What to do

  1. Pick the list again in the Repeat so it takes the kind the list holds.

"Try again" is not available on this step

Error code retry

What Keypress says

<step> cannot try again: <reason>.

Why it happens

  • Try again is set on a step that cannot be repeated safely, such as asking Claude, or its count is out of range.

What to do

  1. Turn Try again off for the step, or set it between 1 and 10 more tries.

A macro runs a PowerShell script

Error code run-script

What Keypress says

<step> runs a PowerShell script.

Why it happens

  • A Run script step is in the macro.

What to do

  1. Read the script before running the macro, and only keep it if you trust where the macro came from.

A step is turned off in a way that cannot work

Error code skipped-node

What Keypress says

<step> cannot be turned off.

Why it happens

  • A Start cannot be turned off: a run begins at it.

What to do

  1. Turn the step back on.

Stop repeating is outside a Repeat

Error code stop-repeating

What Keypress says

Stop repeating is not inside a Repeat, so there is nothing for it to stop.

Why it happens

  • The step was moved or pasted out of the Repeat it belonged to.

What to do

  1. Put the step back inside a Repeat, or delete it.

The steps are not joined up in a way Keypress can run

Error code structure

What Keypress says

<step> has <n> lines leaving by <name>: each one can lead to only one step. / <step> is not connected to anything that starts it, so it would never run.

Why it happens

  • A step has two lines leaving the same place, or a line leaves by a place the step does not have.
  • A line crosses the edge of a Repeat, an If or a Group, or goes back to a step that already ran.
  • A step inside a frame is not joined to the frame's start, or something leads into a Start.
  • The macro file was edited by hand.

What to do

  1. Remove the extra line, or drag the step to where it belongs, so each place leads to one step.
  2. Repeat a group of steps with a Repeat, never by pointing a line back.

A step has a setting this version does not know

Error code unknown-field

What Keypress says

<step> has a setting called <name>, which this build of Keypress does not know.

Why it happens

  • The macro was made in a newer version of Keypress.
  • The macro file was edited by hand.

What to do

  1. Update Keypress and open the macro again.
  2. Or delete the step and add it again from the palette.

A step is not one this version knows

Error code unknown-node-type

What Keypress says

<n> step(s) are of a type this build of Keypress cannot run (<id> (type <type>)): update Keypress, or remove those steps

Why it happens

  • The macro was made in a newer version of Keypress.
  • The macro file was edited by hand, or a step was saved without a type.

What to do

  1. Update Keypress and open the macro again.
  2. Or delete the steps the message names.

A Wait for the screen that cannot finish

Error code wait-screen

What Keypress says

<step>: <reason>.

Why it happens

  • A Wait for the screen to change or settle has no time to give up after, so it would look once and never see anything.
  • A Wait for the screen to settle has to stay still for longer than it is allowed to wait.

What to do

  1. Open the Wait and give it longer to wait, or a shorter time to stay still.

A macro sends a web request

Error code web-request

What Keypress says

<step> sends a request to <host>.

Why it happens

  • A Web request step is in the macro.

What to do

  1. Check the address, and only keep the step if you trust where the macro came from.
