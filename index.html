04 / BUILD, UNDERSTAND, REUSE

A workflow you can own.

Readable steps. Reusable building blocks.
Visibility into what happened and why.

Record a starting point.

Capture mouse and keyboard actions with pause, checkpoint, and stop controls. Review the recording and bring it into your flow rather than starting from a blank canvas.

Debug one step at a time.

Use Check to inspect a macro, then Test run to pause and step through it. Unarmed actions report what they would do while reads still happen. Arm selected nodes when you want them to act. Inspect arrival counts, timing, travelled paths and the target rung that answered. Activity keeps a readable event feed below the canvas, with outcome labels and a close control.

Keep good work reusable.

Group steps into subflows, save them to your library, and insert copies into other macros. Use JSON flows and connected values to keep your automation readable and portable.

Choose where AI helps.

Optional Claude authoring can turn a computer-use session into a proposed flow for review. Add an Ask Claude step where a workflow needs judgement. These features use your Anthropic key and send relevant context to Anthropic.

Your shortcut. Your trigger.

Give each Start node a name and a global hotkey. Use press, toggle or while-held triggers, and start saved macros from the system tray while another app has focus.

An editor that keeps up.

Double-click or press Tab to add a node. Drop one onto a wire to insert it. Copy and paste selections, undo changes, tidy the layout and open macros from a library with flow thumbnails.

Local by default. Ready from the tray.

No account, advertising, or telemetry for core automation. Macros and settings stay on your device. Global hotkeys and the system tray keep saved flows within reach.

A few things
you might be wondering.

Do I need to know how to code?+

No. KeyPress uses a visual flow editor: add actions, connect them, and configure what each step does.

Can I run a macro while the window is closed?+

Yes. Closing the window keeps KeyPress running in the system tray. Start a saved macro from the tray or its global hotkey. Quit KeyPress from the tray when you want to exit.

Do I need AI to use KeyPress?+

No. Build and run visual macros locally. Optional Claude features require your own Anthropic API key and send the context needed for those features to Anthropic.

When and where can I download KeyPress?+

KeyPress has not been released yet. It is planned for the Microsoft Store; a launch date has not been announced. The download link will appear here when KeyPress launches. Until then, try the interactive editor above.
