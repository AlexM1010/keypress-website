CHOOSE THE NEXT STEP

Decide and repeat.

An If checks a value, or whether something is on screen, and runs one lane or the other. A Repeat goes round a set number of times, once for each item in a list, or until something is true. Start with a plain list; add decisions and repeats when your task needs them.

04 / BUILD, UNDERSTAND, REUSE

A workflow you can own.

Readable steps. Reusable building blocks.
Visibility into what happened and why.

Record a starting point.

Capture mouse and keyboard actions with pause, checkpoint, and stop controls. Keypress watches the screen as you go, so the draft waits for what appeared rather than replaying your timing. Review it on the canvas, then keep it - one undo takes it back.

Debug one step at a time.

Use Check to inspect a macro, then Test run to pause and step through it. Unarmed actions report what they would do while reads still happen. Arm selected steps when you want them to act. Inspect arrival counts, timing, travelled paths and the target rung that answered. Activity keeps a readable event feed below the canvas, with outcome labels and a close control.

Keep good work reusable.

Wrap steps in a Group, save it to your library, and insert copies into other macros. Macros are plain JSON files, so your automation stays readable and portable.

Choose where AI helps.

The Assistant edits your macro in a chat, as one undoable change. Optional Claude authoring can turn a computer-use session into a proposed macro for review. Add an Ask step where a macro needs judgement. These features need an optional Keypress subscription and send relevant context to Anthropic through the Keypress service.

Your shortcut. Your trigger.

Give each Start a name and a global hotkey. Use press, toggle or while-held triggers, and start saved macros from the system tray while another app has focus.

An editor that keeps up.

Press Tab or click the + between steps to add one, and drag a step to move it. The layout is automatic, so there is nothing to tidy. Copy and paste selections, undo changes and open macros from a library with thumbnails.

Local by default. Ready from the tray.

No account, advertising, or telemetry for core automation. Macros and settings stay on your device. Global hotkeys and the system tray keep saved flows within reach.

A few things
you might be wondering.

Do I need to know how to code?+

No. A macro is a list of steps that read like sentences: add a step, then click the words in it to change what it does.

Can I run a macro while the window is closed?+

Yes. Closing the window keeps Keypress running in the system tray. Start a saved macro from the tray or its global hotkey. Quit Keypress from the tray when you want to exit.

Do I need AI to use Keypress?+

No. Build and run macros locally. Optional Claude features need an optional Keypress subscription, and send the context needed for those features to Anthropic through the Keypress service. Nothing is sent unless you use one of those features.

When and where can I download Keypress?+

Keypress has not been released yet. It is planned for the Microsoft Store; a launch date has not been announced. The download link will appear here when Keypress launches. Until then, try the interactive editor above.
